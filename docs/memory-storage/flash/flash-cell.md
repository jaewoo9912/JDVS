# Flash 셀 동작 원리 — "문이 달린 구슬 관" 비유

> 요약: flash 셀은 **플로팅 게이트(FG)에 전자를 가둔 트랜지스터**다. 고전압으로 전자를 넣거나(**Program**) 빼서(**Erase**) **Vt(문턱 전압)**를 바꾸고, 저전압으로 채널 전류를 재서(**Read**) 값을 확인한다. Vt는 게이트-소스 전압(V<sub>GS</sub>)의 비교 기준이며, 이 전류를 그대로 입력 × 가중치 계산에 쓰면 아날로그 in-memory 연산(CIM)이 된다.
>
> ※ 셀을 둘러싼 소자·전압 도메인·주변 회로는 [소자 · 전압 레벨 · 도메인](flash-domain.md)에 있다.
>
> ※ 출처: 2026-11-24 플래시 셀 학습 노트 ("문이 달린 구슬 관" 비유).

## 1. 비유 그림과 등장인물

### 1.1 비유 그림

```text
                     손잡이 (위로 당기는 힘)
                     ↑
           ┌────────────────┐             진공청소기
           │  ●●●   보관함   │  ←──────────  (Erase 때만 켬)
           └────────────────┘
         ══════ 두꺼운 벽 ══════
 입구 ○○○ ──→  [ 문 ]  ──→ ○○○ 출구
 뒤에서 미는 힘
```

### 1.2 비유 ↔ 실제 용어

| 비유 | 실제 용어 | 설명 |
|---|---|---|
| 구슬 | 전자 | 모두 같은 전자. 위치에 따라 역할이 다름 |
| 관 속 구슬 ○ | 채널 전자 (흐르는 전자) | 입구(소스)에서 계속 공급되어 출구(드레인)로 흐름 |
| 보관함 속 구슬 ● | 저장 전자 | 갇혀서 움직이지 않음. **이것이 기억하는 값** |
| 보관함 | 플로팅 게이트 (FG) | 채널 바로 위에 위치 |
| 두꺼운 벽 | 절연막 (에너지 장벽) | 평소엔 전자가 못 넘음. 고전압일 때만 넘음 |
| 문 | 채널 | 열려야 채널 전자가 지나감 |
| 손잡이 당기는 힘 | 게이트-소스 전압 (V<sub>GS</sub>) | 채널을 여는 힘 |
| 뒤에서 미는 힘 | 소스-드레인 전압 | 채널 전자를 드레인으로 보내는 힘 |
| 출구로 나온 구슬 수 | 전류 | 단위 시간당 지나가는 전자 수 |
| 진공청소기 | Erase Gate (EG) | FG의 전자를 빼낼 때만 사용 |

---

## 2. 전자는 두 무리 — 저장 전자 vs 채널 전자

| | 저장 전자 (보관함) | 채널 전자 (관) |
|---|---|---|
| 위치 | 플로팅 게이트 안 | 채널 안 |
| 움직임 | 움직이지 않음 | 계속 흐름 |
| 역할 | **값을 기억** | **전류를 만듦** |
| 출처 | Program 때 채널 전자 일부가 주입된 것 | 전원이 계속 공급 |

- **전류 = 채널 전자의 흐름**이다. 저장 전자는 흐르지 않는다.
- 저장 전자는 같은 (−)전하라서 채널 전자를 **밀어내** 흐름을 방해한다.
- 저장 전자가 많을수록 채널 전류가 줄어든다.

---

## 3. 핵심 규칙 두 가지

### 3.1 규칙 ① 저장 전자가 채널을 여는 것을 방해한다

| FG 저장 전자 | 채널을 열기 위한 V<sub>GS</sub> |
|---|---|
| 많음 | 높아야 열림 (문이 무거움) |
| 적음 | 낮아도 열림 |

- **채널이 열리기 시작하는 최소 게이트-소스 전압(V<sub>GS</sub>) = Vt (Threshold Voltage, 문턱 전압)**

### 3.2 규칙 ② 에너지 장벽은 고전압에서만 넘는다

- 평소의 낮은 전압으로는 전자가 절연막을 넘지 못한다. 그래서 **전원을 꺼도 값이 유지된다** (비휘발성).
- 고전압일 때만 전자가 FG에 드나든다.
- 즉 FG는 완전 밀봉이 아니라 **아주 높은 에너지 장벽이 있는 상자**다.

---

## 4. 에너지 장벽과 Vt는 다른 것

| | 에너지 장벽 (절연막) | Vt (문턱 전압) |
|---|---|---|
| 무엇의 문턱인가 | 전자가 FG에 **드나드는** 문턱 | 채널 전자가 **흐르기 시작하는** 문턱 |
| 넘으면 | 저장 전자 수가 바뀜 (값 변경) | 전류가 흐름 (값 읽기) |
| 관련 동작 | Program / Erase | Read |
| 값이 바뀌나 | 재료로 정해져 **고정** | 저장 전자 양에 따라 **변함** |
| 필요한 전압 | 아주 높음 (약 10~12V) | 낮음 (약 1V 내외) |

```text
고전압으로 장벽을 넘겨 저장 전자 수 변경 → Vt 변화 → Read 시 전류 변화
```

---

## 5. 두 종류의 전압 — 게이트-소스 전압 vs 소스-드레인 전압

| | 게이트-소스 전압 (V<sub>GS</sub>) | 소스-드레인 전압 |
|---|---|---|
| 비유 | 손잡이 당기는 힘 | 구슬 미는 힘 |
| 하는 일 | 채널을 **열지 말지, 얼마나 열지** 결정 | 열린 채널로 전자를 **실제로 보냄** |
| 방향 | 위에서 아래 (채널과 수직) | 소스에서 드레인 (채널을 따라) |
| 전류 | 게이트 자체로는 거의 안 흐름 (조절만 함) | 실제 전류가 흐르는 경로 |
| Vt와의 관계 | **Vt와 직접 비교** | Vt와 무관 |

**둘 다 있어야 전류가 흐른다.**

| 게이트 (채널) | 소스-드레인 전압 | 전류 |
|---|---|---|
| 닫힘 | 있음 | 흐르지 않음 |
| 열림 | 없음 | 흐르지 않음 |
| 열림 | 있음 | **흐름** |

---

## 6. Vt는 게이트-소스 전압(V<sub>GS</sub>)의 비교 기준

- **V<sub>GS</sub> = V<sub>G</sub> − V<sub>S</sub>** (소스 기준 게이트 전압). 게이트 전압 자체가 아니라 이 값을 Vt와 비교한다.
- **V<sub>GS</sub> > Vt** 이면 채널이 형성되어(열려) 전류가 흐를 수 있다.
- **소스-드레인 전압 > 0** 이면 전자를 보낸다. Vt와 비교하지 않는다.
- **V<sub>GS</sub> − Vt = 채널이 열린 정도**

| V<sub>GS</sub> vs Vt | 채널 | 전류 |
|---|---|---|
| V<sub>GS</sub> < Vt | (거의) 닫힘 | 거의 안 흐름 |
| V<sub>GS</sub> ≈ Vt | 막 열리기 시작 | 아주 조금 |
| V<sub>GS</sub> > Vt | 열림 | 차이가 클수록 많이 |

!!! tip "왜 게이트 전압이 아니라 V<sub>GS</sub>인가"
    소스가 항상 0V는 아니다. 소스에 전압이 걸려 있으면 같은 게이트 전압이라도 채널이 열리는 정도가 달라지므로, 소스 기준 전압 V<sub>GS</sub>로 비교한다.

!!! tip "sub-threshold 영역"
    V<sub>GS</sub>가 Vt보다 조금 낮아도 nA 수준의 미세 전류가 흐른다(**sub-threshold 영역**). 저전력 아날로그 연산에서는 이 영역을 쓰기도 한다.

## 7. 셀 동작 — Read / Program / Erase / Read-Verify

### 7.1 Read (읽기)

- V<sub>GS</sub>는 적당히, 소스-드레인 전압은 약하게 건다 (저전압).
- 드레인 쪽 **BL(Bit Line)로 나온 전류**를 측정한다.
- 장벽을 넘지 못하므로 저장된 값은 그대로다.

| BL 전류 | FG 저장 전자 |
|---|---|
| 많음 | 적음 |
| 적음 | 많음 |

### 7.2 Program (쓰기)

- **SL 고전압**으로 채널 전자를 세게 가속하고, **CG 고전압**으로 위로 강하게 끌어당긴다.
- 빠르게 달리던 전자 일부가 장벽을 넘어 FG에 들어간다 (**Hot Electron Injection**).
- 저장 전자 증가 → **Vt 상승 → 전류 감소**

### 7.3 Erase (지우기)

- **EG 고전압**을 건다.
- FG의 전자가 장벽을 뚫고 빠져나간다 (**FN 터널링**, Fowler-Nordheim).
- 저장 전자 감소 → **Vt 하강 → 전류 증가**
- 여러 셀(**sector**)을 한꺼번에 지운다.

### 7.4 Read-Verify (확인)

Program을 조금씩 하고 매번 Read로 전류를 확인해, 목표 전류에 도달할 때까지 반복한다.

```mermaid
flowchart LR
    P[Program<br/>전자 조금 주입] --> V[Verify<br/>전류 측정]
    V -->|목표보다 많음| P
    V -->|목표 도달| D[PASS · 종료]
```

### 7.5 동작 요약

| 동작 | 전압 | 저장 전자 | 결과 |
|---|---|---|---|
| Program | CG, SL 고전압 | 들어감 | Vt ↑, 전류 ↓ |
| Erase | EG 고전압 | 빠져나감 (sector 단위) | Vt ↓, 전류 ↑ |
| Read | 저전압 | 그대로 | 전류로 값 확인 |
| Read-Verify | 저전압 | 그대로 | 목표 도달 PASS/FAIL |

## 8. 단자 약자

| 약자 | 풀네임 | 역할 | 비유 |
|---|---|---|---|
| CG | Control Gate | 채널을 여는 전압을 건다. Program 때 전자를 위로 끌어당김 | 손잡이 |
| SL | Source Line | 전류 입구(소스) 쪽 선. Program 때 고전압으로 전자 가속 | 입구 + 미는 힘 |
| EG | Erase Gate | Erase 전용. 고전압으로 FG 전자를 빼냄 | 진공청소기 |
| WL | Word Line | 가로줄(row) 선택 | 이 줄 켜기 |
| BL | Bit Line | 전류 출구(드레인) 쪽 세로줄(column). 여기서 전류를 읽음 | 출구 |
| FG | Floating Gate | 전자를 가둬 값 저장. 어디에도 연결되지 않음 | 보관함 |

!!! tip "전압 trim"
    CG, EG, SL에 거는 전압은 보통 trim 설정으로 미세 조정한다.

## 9. 게이트는 문턱이 아니다 — Gate / Vt / Channel

| 용어 | 정체 | 비유 |
|---|---|---|
| 게이트 (Gate) | 전압을 거는 **부품(전극)** | 손잡이 |
| Vt (Threshold Voltage) | 채널이 열리기 시작하는 **전압 값** | 최소 손잡이 힘 |
| 채널 (Channel) | 전류가 지나가는 길 | 문 |

- 문턱(threshold)에 해당하는 것은 **Vt**다.
- 영어 gate는 "문"이지만, 트랜지스터에서는 **문을 조종하는 손잡이(전극)**를 뜻한다.
- CG(손잡이), EG(청소기), FG(보관함)는 이름에 모두 gate가 붙지만 역할이 다르다.

!!! warning "용어 혼동 주의"
    게이트-소스 전압(V<sub>GS</sub>)이 **Vt(문턱)**를 넘으면 **채널(문)**이 열린다. 게이트 = 문턱이 아니다.

## 10. Gate와 Line — 둘 다 물리적 구조물

### 10.1 Gate = 셀 하나 안의 층

```text
  [ CG ]       ← 폴리실리콘 층 (전극)
  ─ 절연막 ─
  [ FG ]       ← 폴리실리콘 층 (어디에도 연결 안 됨)
  ─ 절연막 ─
  실리콘 기판 (채널, 소스, 드레인)
```

- 소스와 드레인은 실리콘 기판에 불순물을 주입(doping)해 만든 영역이다.

### 10.2 Line = 여러 셀을 잇는 배선

```text
        BL0     BL1     BL2      ← 세로 배선 (각 셀의 드레인 연결)
         │       │       │
WL0 ════[셀]════[셀]════[셀]════  ← 가로 배선 (각 셀의 게이트 연결)
         │       │       │
WL1 ════[셀]════[셀]════[셀]════
```

| 라인 | 방향 | 연결 |
|---|---|---|
| WL / CG 라인 | 가로 (row) | 셀 위를 지나는 부분이 곧 그 셀의 게이트 |
| BL | 세로 (column) | 각 셀의 드레인. 같은 세로줄 전류가 여기서 합쳐짐 |
| SL | — | 각 셀의 소스 |

| | Gate | Line |
|---|---|---|
| 범위 | 셀 하나 안 | 여러 셀을 관통 |
| 정체 | 트랜지스터의 전극 층 | 셀들을 잇는 배선 |
| 관계 | 라인이 셀 위를 지나는 부분이 게이트 | 게이트들을 이어 놓은 것 |

- **row 주소(X-address)**로 가로줄(WL/CG)을, **column 주소(Y-address)**로 세로줄(BL)을 선택한다.

## 11. Control Gate vs 일반 Gate

**역할은 같고(채널을 여는 손잡이), 중간에 FG가 끼어 있다는 점이 다르다.**

```text
 일반 트랜지스터           flash 셀
  [ Gate ]               [ CG ]     ← 손잡이
  ─ 절연막 ─              ─ 절연막 ─
  채널                    [ FG ]     ← 보관함
                          ─ 절연막 ─
                          채널
```

| | 일반 Gate | Control Gate |
|---|---|---|
| 채널과의 거리 | 바로 위 | FG를 사이에 두고 위 |
| 힘 전달 | 직접 | FG를 거쳐 간접 (커플링 비율만큼) |
| Vt | 제조 시 고정 | FG 전자 양에 따라 변함 |

- FG에 전자가 많으면 CG의 전압 효과가 그만큼 상쇄된다. **이것이 Vt가 바뀌는 이유**다.

### 11.1 SST split-gate 구조

```text
        [ WL ]      [ CG ]
                    [ FG ]
  소스 ─ 채널① ──── 채널② ─ 드레인
       (WL 아래)   (FG 아래)
```

| 구간 | 여는 주체 | 역할 |
|---|---|---|
| 채널① (WL 아래) | WL이 직접 | 일반 게이트처럼 동작하는 **선택 스위치** |
| 채널② (FG 아래) | CG가 FG를 거쳐 | **저장된 값**에 따라 열리는 정도가 다름 |

- 두 구간이 **모두 열려야** 전류가 흐른다.
- 채널②의 Vt 비교도 CG의 절대 전압이 아니라 **CG-소스 간 전압** 기준이다 (FG 커플링을 거쳐 전달).

## 12. 응용 — flash 셀을 이용한 아날로그 in-memory 연산 (CIM)

```text
BL 전류 = 입력 (게이트 전압, DAC가 인가) × 가중치 (FG 저장 전자 양)
```

| 비유 | CIM에서의 의미 |
|---|---|
| 보관함 속 구슬 양 | 가중치 (미리 Program) |
| 손잡이 당기는 힘 | 입력값 (DAC가 디지털 값을 게이트 전압으로 변환) |
| 출구로 나온 구슬 수 | 입력 × 가중치 (곱셈) |
| 여러 관의 출구가 한 통으로 모임 | 세로줄(BL)의 전류 합 = 덧셈 |
| 통의 구슬을 세서 숫자로 적음 | ADC가 디지털 값으로 변환 |

- 셀 하나의 전류는 음수가 될 수 없으므로, **셀 2개를 차동 쌍(+/−)으로 묶어 음수 가중치**를 표현한다.

## 13. 한 줄 정리

| 항목 | 내용 |
|---|---|
| 저장 | FG에 전자를 가둬 값 저장 (비휘발성) |
| 쓰기 / 지우기 | 고전압으로 장벽을 넘겨 전자 주입(Program) / 제거(Erase) → Vt 변화 |
| 읽기 | 저전압으로 채널 전류 측정 (Read) |
| Vt | V<sub>GS</sub>의 비교 기준. 저장 전자 양에 따라 변함 |
| 응용 | 셀 전류를 입력 × 가중치 연산에 그대로 사용 (CIM) |
