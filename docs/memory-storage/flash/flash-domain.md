# 소자 · 전압 레벨 · 도메인

> 요약: **소자**는 트랜지스터이고, **절연막(벽)이 얇을수록 빠르고 작지만 높은 전압에 약하다.** 그래서 칩은 **약 1V 디지털(VDD_CORE), 약 1.8V 아날로그(VDD_IO), 약 12V 고전압(HV)**으로 전압 도메인을 나눠 각자 맞는 두께의 트랜지스터로 주변 회로를 만들고, 도메인 사이는 **레벨 시프터**로 잇는다. flash 셀은 이 도메인들로부터 동작별 전압을 받는 **플래시 전용 소자**다.
>
> ※ 셀 자체의 동작(FG, Vt, Program/Erase/Read)은 [Flash 셀 동작 원리](flash-cell.md)에 있다.
>
> ※ 출처: 2026-11-24 "소자 · 레벨 · 도메인 정리" 학습 노트.

---

## 1. 소자 = 트랜지스터

- **소자**: 칩을 이루는 가장 기본 부품. 여기서는 **트랜지스터**를 말한다.
- 트랜지스터 = 손잡이(게이트)로 문(채널)을 여닫는 스위치
- 게이트와 채널 사이 **절연막(벽)의 두께**가 소자의 성격을 정한다.

```text
얇은 절연막 트랜지스터        두꺼운 절연막 트랜지스터
  [게이트]                   [게이트]
  ─ 얇은 벽 ─                ═══ 두꺼운 벽 ═══
  [ 채널 ]                   [ 채널 ]
```

| | 얇은 절연막 | 두꺼운 절연막 |
|---|---|---|
| 속도 | 빠름 | 느림 |
| 크기 | 작음 (집적도 높음) | 큼 |
| 전력 | 적음 | 많음 |
| 내압 (견디는 전압) | 낮음 (높으면 절연막 파괴) | 높음 |

!!! tip "트레이드오프"
    빠르고 작으면서 고전압까지 견디는 트랜지스터는 없다. 그래서 필요한 전압에 맞춰 골라 쓴다.

- flash 셀은 그중 **플로팅 게이트(보관함)가 추가된 특수 트랜지스터**다.

## 2. 전압 레벨 = 핀이 쓰는 전압 범위 (도메인)

| 레벨 | 전압 | 신호 | 소자 | 비유 | 해당 핀 |
|---|---|---|---|---|---|
| VDD_CORE (코어 전원) | 약 1V (0.9~1.1V) | 디지털 0/1 | 얇은 절연막 (코어 소자) | 고무호스 | 제어·주소·데이터 핀 거의 전부 |
| VDD_IO (IO/아날로그 전원) | 약 1.8V (1.62~1.98V) | 아날로그 정밀 전압 | 중간 절연막 (IO 소자) | PVC 관 | 아날로그 바이어스·기준 전압 핀 |
| HV | 약 12V | 고전압 | 아주 두꺼운 절연막 (HV 소자) | 강철 배관 | 고전압 공급 핀 |

| 레벨 | 값의 의미 |
|---|---|
| VDD_CORE | 논리 레벨만 의미. **VIL ≤ 0.1 × VDD_CORE → 0**, **VIH ≥ 0.9 × VDD_CORE → 1** |
| VDD_IO | 전압 값 자체가 의미 (예: 기준 전압 1.2V, Read 바이어스) |
| HV | Program/Erase 때 셀에 거는 고전압. 로직과 완전히 분리해야 함 |

- 테스트용 아날로그 IO 핀은 위 레벨 구분과 별도로 분류한다.

---

## 3. 도메인을 나누는 이유

**전압이 높을수록 소자를 두껍고 크게 만들어야 하기 때문이다.** 고무호스에 소방차 수압을 걸면 터지고, 모든 배관을 강철로 만들면 너무 크고 느리다.

| 도메인 | 하는 일 | 그 전압인 이유 |
|---|---|---|
| VDD_CORE | 제어 신호, 레지스터, 로직 | 0/1만 구분하면 되니 최대한 낮게 |
| VDD_IO | Read 바이어스, DAC/ADC, 기준 전압 | 정밀도를 위해 여유 있게 |
| HV | Program/Erase (셀의 절연막을 넘김) | 전자가 장벽을 넘으려면 높을 수밖에 없음 |

- 각 도메인은 그 전압을 견딜 수 있는 두께의 트랜지스터로 만든다.

### 3.1 디지털이 가장 낮은 레벨을 쓰는 이유

| 이유 | 효과 |
|---|---|
| **0/1만 구분하면 된다** | 1V로 충분. 0과 1 사이 noise margin이 커서 노이즈에도 안전 |
| **동적 전력 ∝ 전압² × 스위칭 횟수** | 1.8V 대신 1V면 전력 약 1/3 |
| **얇은 절연막 트랜지스터를 쓸 수 있다** | 작고 빨라서 많이, 빠르게 동작 |

### 3.2 도메인 사이 연결 — 레벨 시프터

```text
제어 로직 (1V) ── Program 명령 ──▶ [레벨 시프터] ──▶ 12V 스위치 ON ──▶ 셀에 고전압
```

- **레벨 시프터**: 1V 신호로 12V 스위치를 켜라는 명령을 전달하는 중계기

## 4. 주변 회로와 셀의 관계

### 4.1 도메인에 속한 것 = 주변 회로 (peripheral circuit)

| 하는 일 | 예 | 도메인 |
|---|---|---|
| 결정·명령 | Read인지 Program인지, 어느 셀인지 해석 | VDD_CORE |
| 전압 생성 | 차지 펌프로 12V 생성, 정밀 바이어스 생성 | HV, VDD_IO |
| 전달·선택 | HV 스위치·드라이버로 선택한 셀 단자에만 연결 | HV, VDD_IO |
| 변환 | DAC (숫자 → 전압), ADC (전류 → 숫자) | VDD_IO |
| 판별 | 센스 앰프로 셀 전류를 기준과 비교 | VDD_IO |

- 주변 회로도 전부 트랜지스터다. **각자 다루는 전압을 견딜 두께**로 만든다.
- **셀** = 값을 저장하고 계산하는 곳 / **주변 회로** = 셀을 동작시키고 결과를 꺼내는 곳

### 4.2 셀은 어느 도메인에도 속하지 않는 전용 소자

```text
   [VDD_CORE: 얇은 소자] → [VDD_IO: 중간 소자]  → ┐
     명령·제어              DAC/ADC/바이어스       ├→ [셀: 플래시 전용 소자]
                        → [HV: 두꺼운 소자]    → ┘     저장 + 계산
                            차지 펌프/HV 스위치
```

| 동작 | 셀 단자에 걸리는 전압 | 공급 도메인 |
|---|---|---|
| Read | WL·CG에 입력 전압, BL에 약한 바이어스 | VDD_IO |
| Program | CG·SL에 고전압 | HV |
| Erase | EG에 고전압 | HV |
| 언제 무엇을 할지 결정 | (셀에 직접 걸리지 않음) | VDD_CORE |

!!! warning "같은 단자, 다른 전압"
    같은 CG 단자라도 Read 때는 1V대, Program 때는 10V대가 걸린다. 그래서 셀 근처에 경로를 바꿔 끼우는 **HV 스위치/드라이버**(HV 소자로 제작)가 필요하다.

### 4.3 셀 자체의 절연막

| 셀 안의 절연막 | 위치 | 설계 목표 |
|---|---|---|
| FG ↔ 채널 | 보관함과 문 사이 | 평소엔 전자를 가두고, Program 고전압일 때만 넘게 |
| CG ↔ FG | 손잡이와 보관함 사이 | CG 전압이 FG로 잘 전달되면서 고전압에 버팀 |
| EG ↔ FG | 청소기와 보관함 사이 | Erase 고전압일 때 전자가 뚫고 나가게 |

| | 일반 트랜지스터 | flash 셀 |
|---|---|---|
| 절연막 설계 | 전자가 **절대 넘지 않게** (넘으면 파괴·고장) | 평소엔 안 넘고, **고전압일 때만 정해진 만큼** 넘게 |
| 공정 | 일반 로직 공정 | **플래시 전용 공정** |

- 그래서 셀은 일반 도메인 소자와 공정부터 다른 전용 소자다.
