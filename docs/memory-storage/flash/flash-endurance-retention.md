# Endurance와 Retention

> 요약: 둘 다 **플로팅 게이트를 둘러싼 절연막(두꺼운 벽)**과 관련된 신뢰성 지표다. **Endurance**는 절연막이 버틸 수 있는 **쓰기/지우기(P/E cycle) 반복 횟수**, **Retention**은 전원을 꺼 두어도 **값이 유지되는 기간(데이터 보존)**이다. 많이 쓸수록 절연막이 손상되어 Retention도 줄어든다.
>
> ※ 비유(구슬 = 전자, 보관함 = 플로팅 게이트, 두꺼운 벽 = 절연막)와 Vt는 [Flash 셀 동작 원리](flash-cell.md)를 따른다.
>
> ※ 출처: 2026-11-24 "Endurance와 Retention" 학습 노트.

---

## 1. Endurance — 몇 번까지 다시 쓸 수 있나

| 동작 | 비유 | 실제 |
|---|---|---|
| Program | 고전압으로 구슬을 **두꺼운 벽 너머 보관함에 밀어 넣음** | 전자를 절연막 너머 플로팅 게이트에 주입 |
| Erase | **청소기(EG)로 빨아냄** | EG 고전압으로 플로팅 게이트의 전자를 제거 |

- 전자가 절연막을 억지로 넘을 때마다 **절연막이 조금씩 손상된다** (절연막 안에 전자가 박히는 **전하 트랩**, 작은 결함 발생).
- 반복하면 절연막이 열화되어 아래 두 가지 문제가 생긴다.

| 열화 증상 | 결과 |
|---|---|
| 전자를 넣고 빼기가 점점 어려워짐 | Program/Erase가 느려지거나 실패 |
| 플로팅 게이트에서 전자가 더 잘 샘 | Retention 감소 |

- **Program + Erase 한 쌍 = 1 cycle (P/E cycle)**로 세고, "몇 cycle까지 보장"으로 표시한다.

!!! tip "정의"
    **Endurance = 절연막이 버틸 수 있는 쓰기/지우기 반복 횟수 (P/E cycle)**

---

## 2. Retention — 써 둔 값이 얼마나 오래 유지되나

- 플로팅 게이트는 완전히 밀봉된 것이 아니라 **두꺼운 절연막**으로 둘러싸인 것이다.
- 평소에는 전자가 절연막을 넘지 못하지만, 아주 드물게 **조금씩 새어 나간다**.
- **온도가 높을수록** 더 빨리 샌다.

```text
전자 누설 → Vt 변화 → 읽기 전류 변화 → 저장한 값이 틀어짐
```

!!! tip "정의"
    **Retention = 전원을 꺼 두어도 값이 유지되는 기간 (데이터 보존)**

---

## 3. 둘의 관계

| | Endurance | Retention |
|---|---|---|
| 질문 | 몇 번 다시 쓸 수 있나 | 한 번 쓰면 얼마나 오래 가나 |
| 원인 | 쓰기/지우기 때 절연막 손상 | 평소에 전자가 조금씩 샘 |
| 단위 | cycle (횟수) | 년 (기간) |

- 둘은 연결되어 있다: **많이 쓸수록(Endurance 소모) 절연막이 손상되어 더 잘 샌다(Retention 감소)**.
- 그래서 보통 **"정해진 횟수만큼 쓴 뒤에도 몇 년 유지된다"**는 식으로 함께 보장한다.

!!! warning "아날로그 값을 저장하는 플래시"
    아날로그 값을 저장하는 플래시는 전자가 **조금만 새도** 값이 틀어진다. 그래서 0/1만 저장하는 일반 플래시보다 Endurance·Retention 수치가 작게 나온다.
