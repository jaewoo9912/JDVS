# NMOS·PMOS 기본 개념

> 요약: MOSFET은 게이트 전압으로 소스-드레인 사이 전류를 여닫는 **스위치**다. 켜지는 기준은 게이트 전압 자체가 아니라 **게이트-소스 전압 V<sub>GS</sub> = V<sub>G</sub> − V<sub>S</sub>와 Vt(문턱 전압)의 비교**다. NMOS는 게이트가 높을 때, PMOS는 게이트가 낮을 때 켜진다. 소스가 고정되어야 확실한 0/1이 나오므로, **NMOS는 GND 쪽에, PMOS는 VDD 쪽에** 둔다.
>
> ※ flash 셀에서 V<sub>GS</sub>와 Vt를 비교하는 이유는 [Flash 셀 동작 원리 — 6절](flash-cell.md#6-vt-vgs)에 있다.
>
> ※ 출처: 2026-11-24 "NMOS · PMOS 기본 개념" 학습 노트. 예시 전압(VDD = 1.8V, Vt = 0.5V)은 이해를 위한 값이며 특정 칩의 수치가 아니다.

---

## 1. 트랜지스터(MOSFET) — 단자 세 개

MOSFET은 게이트 전압으로 소스-드레인 사이 전류를 여닫는 **스위치(문)**다. 단자는 세 개다.

| 단자 | 연결 (인버터 기준) | 역할 |
|---|---|---|
| 게이트 (G) | IN | 신호 입력 (전압). 스위치를 켤지 끌지 결정 |
| 소스 (S) | VDD 또는 GND | 전원 공급. **고정된 전압** (신호 아님) |
| 드레인 (D) | OUT | 출력. 결과 전압이 나오는 곳 (변함) |

---

## 2. 켜지는 기준 — Vt와 V<sub>GS</sub>

게이트 전압 **자체**가 아니라 **V<sub>GS</sub> = V<sub>G</sub> − V<sub>S</sub>**를 Vt와 비교한다.

| 종류 | 켜지는 조건 |
|---|---|
| NMOS | V<sub>GS</sub> > Vt |
| PMOS | 게이트가 소스보다 \|Vt\| 이상 낮음 (소스 − 게이트 > \|Vt\|, 즉 V<sub>GS</sub> < −\|Vt\|) |

- 소스가 0V에 고정이면 V<sub>GS</sub> = 게이트 전압이라, "게이트만 보는 것"처럼 보인다.

같은 게이트 전압이라도 소스가 다르면 결과가 달라진다 (Vt = 0.5V 예시).

| 게이트 (V<sub>G</sub>) | 소스 (V<sub>S</sub>) | V<sub>GS</sub> | 결과 |
|---|---|---|---|
| 1.8V | 0V | 1.8V | 켜짐 |
| 1.8V | 1.5V | 0.3V | 꺼짐 |

!!! tip "sub-threshold"
    Vt 아래에서도 전류가 아주 조금 흐른다(**sub-threshold 영역**). Vt는 "전류가 0에서 생기는 점"이 아니라 **"쓸 만한 전류가 생기는 경계"**다.

---

## 3. NMOS vs PMOS

같은 MOSFET의 두 종류다. 하는 일(전류를 흘리거나 막기)은 같고, **켜지는 조건만 정반대**다.

| | NMOS | PMOS |
|---|---|---|
| 켜지는 조건 | 게이트 **높음** | 게이트 **낮음** |
| 소스 위치 | GND (0V) | VDD (전원, 예 1.8V) |
| 주로 놓는 자리 | 아래 (GND 쪽) | 위 (VDD 쪽) |
| 잘 만드는 값 | **0** | **1** |
| 비유 | 당기면 열리는 문 | 밀면 열리는 문 |

!!! tip "CMOS"
    CMOS는 소자 이름이 아니라 NMOS + PMOS를 짝지어 쓰는 **회로 방식**이다 (C = Complementary).

---

## 4. 왜 NMOS는 GND 쪽, PMOS는 VDD 쪽에 두나

핵심은 **소스가 고정되느냐, OUT을 따라 움직이느냐**다.

```text
        VDD
         │
      [ PMOS ]     ← 소스 = VDD 고정 → 확실한 1
         │
IN ────  ┤ 게이트
         │
        OUT
         │
      [ NMOS ]     ← 소스 = GND 고정 → 확실한 0
         │
        GND
```

### 4.1 NMOS를 GND 쪽에 두면 — 확실한 0

- 소스가 GND 선에 직접 연결되므로 항상 0V로 고정된다.
- IN = 1.8V로 켜면, OUT(드레인)이 내려가는 동안에도 V<sub>GS</sub> = 1.8V 그대로다.

| OUT | 게이트 | 소스 | V<sub>GS</sub> | 스위치 |
|---|---|---|---|---|
| 1.8V | 1.8V | 0V | 1.8V | 켜짐 |
| 0.9V | 1.8V | 0V | 1.8V | 켜짐 |
| 0V | 1.8V | 0V | 1.8V | 켜짐 (0V에 도착) |

스위치가 끝까지 켜져 있어서 OUT이 **딱 0V**까지 내려간다.

### 4.2 NMOS를 VDD 쪽에 두면 — 약한 1

- OUT이 소스가 된다. OUT이 올라갈수록 V<sub>GS</sub>가 줄어든다.
- OUT ≈ VDD − Vt에서 꺼져서 1.8V까지 올라가지 못한다.

### 4.3 PMOS를 VDD 쪽에 두면 — 확실한 1

- PMOS의 소스가 VDD 선(1.8V)에 직접 연결되므로 항상 1.8V로 고정된다.
- PMOS는 게이트가 소스보다 |Vt| 이상 **낮아야** 켜진다. 비교값은 **소스 − 게이트** (= −V<sub>GS</sub>)다.
- IN = 0V를 넣으면 소스(1.8V) − 게이트(0V) = 1.8V > |Vt| → 켜진다.
- 켜지면 OUT(드레인)이 VDD 선과 이어져서 0V에서 위로 올라간다.
- 올라가는 동안에도 소스는 1.8V, 게이트는 0V 그대로이므로 차이 1.8V가 유지된다.

| OUT | 게이트 | 소스 | 소스 − 게이트 | 스위치 |
|---|---|---|---|---|
| 0V | 0V | 1.8V | 1.8V | 켜짐 |
| 0.9V | 0V | 1.8V | 1.8V | 켜짐 |
| 1.7V | 0V | 1.8V | 1.8V | 켜짐 |
| 1.8V | 0V | 1.8V | 1.8V | 켜짐 (1.8V에 도착) |

스위치가 끝까지 켜져 있어서 OUT이 **딱 1.8V**까지 올라간다.

### 4.4 PMOS를 GND 쪽에 두면 — 약한 0

- 이번엔 OUT이 PMOS의 소스가 된다 (드레인이 GND 쪽).
- IN = 0V로 켜서 OUT을 1.8V에서 내리려 해도, OUT(소스)이 내려갈수록 소스 − 게이트 차이가 줄어든다.

| OUT (= 소스) | 게이트 | 소스 − 게이트 | 스위치 (Vt = 0.5V 예시) |
|---|---|---|---|
| 1.8V | 0V | 1.8V | 켜짐 |
| 0.9V | 0V | 0.9V | 켜짐 |
| 0.5V | 0V | 0.5V (= Vt) | **꺼짐** |

OUT이 약 0.5V(= |Vt|)에서 멈춰서 0V까지 내려가지 못한다. 이것이 **약한 0**이다.

### 4.5 배치 정리

| 배치 | 소스 | 결과 |
|---|---|---|
| NMOS가 GND 쪽 | 0V 고정 | 확실한 0 |
| PMOS가 VDD 쪽 | 1.8V 고정 | 확실한 1 |
| 반대로 두면 | OUT을 따라 움직임 | 중간에 꺼짐 → 애매한 값 |

!!! tip "비유"
    소스가 고정된 쪽은 **바닥에 발을 딛고 줄을 당기는 사람**(끝까지 당김)이고, 움직이는 쪽은 **같이 끌려가면서 당기는 사람**(중간에 힘이 빠짐)이다.
