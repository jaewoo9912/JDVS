# 분포 제어 (dist / randcase)

## 세 도구

| 도구 | 본질 | 위치 | 분포 보장 |
| --- | --- | --- | --- |
| `dist`     | 변수 값의 가중치 분포    | constraint 안   | 확률적 (편차 있음) |
| `randcase` | 코드 경로의 가중치 선택  | 절차적 코드     | 확률적 |
| `randc`    | 사이클 단위 균등 (순열)  | 변수 선언       | 결정적 (편차 0) |

→ 다른 차원의 문제: **변수 값 / 실행 경로 / 커버리지 보장**.

---

## `dist` — 가중치 분포

```systemverilog
constraint c {
  size dist { 1 :/ 50, 2 :/ 30, [4:64] :/ 20 };
}
```

### `:=` (값별 가중치) vs `:/` (범위별 가중치)

| | 의미 | 범위 `[a:b]` (N개 값)에 적용 시 |
| --- | --- | --- |
| `:=` | 범위 안 **각 값**에 가중치 W | 그 범위 **총** 가중치 = N × W |
| `:/` | 범위 **전체**에 가중치 W     | 그 범위 안 **각 값** = W/N |

같은 예제 `dist { 0 ? 50, [1:10] ? 50 }`:

- `:=` → 0 가중치 50, `[1:10]` **각** 50 (총 550). **P(0) ≈ 9%**
- `:/` → 0 가중치 50, `[1:10]` **전체** 50 (총 100). **P(0) = 50%**

→ 의도가 *"범위 전체 N%"*면 `:/`. *"범위 안 각 값에 N"*이면 `:=`.
**대부분의 DV 코드는 `:/`가 정답.**

### 규칙

- **가중치는 비율로 정규화** (합이 100일 필요 없음)
- `dist`에 **없는 값은 가중치 0** → 안 뽑힘
- 다른 constraint로 잘리는 값은 **비율 재계산**
- `dist` 위치: **constraint 블록 또는 `with { }` 안에만** (절차적 statement로 못 씀)

### 활용 패턴

```systemverilog
// 경계값 강화 (가장 흔함)
psn dist { 0 :/ 5, [1:MAX-1] :/ 90, MAX :/ 5 };

// 작은 값 편향
burst_len dist { 1 :/ 50, [2:4] :/ 30, [5:64] :/ 20 };

// 가중치를 변수로
drop dist { 1 := ratio, 0 := 100 - ratio };
```

## `randcase` — 절차적 가중치 분기

```systemverilog
randcase
  70: do_normal();
  20: do_error();
  10: do_burst();
endcase
```

- **절차적 코드**의 한 자리에서 가중치별 분기
- **솔버 무관**, 그 순간 결정
- 가중치 합은 무엇이든 OK (비율로 정규화)
- **시퀀스의 시나리오 분기**에 자주 사용

---

## `dist` 균등 vs `randc` — 같아 보이지만 다름

`randc`의 상세는 [기본 페이지의 rand vs randc](basics.md#rand-vs-randc) 참조.

작은 도메인을 균등 분포로 쓰고 싶을 때 둘 다 후보이지만:

- **`dist`** 25/25/25/25: 평균 25에 수렴, **±몇 편차** 있음 (예: 23/27/24/26)
- **`randc`**: 항상 **정확히** 25/25/25/25 (편차 0)
- `randc`는 **균등만 가능** — 가중치/비균등은 `dist`만

→ **결정적 균등 = `randc`**, **확률적 가중치 = `dist`**.

## 시나리오별 도구 선택

| 원하는 것 | 도구 |
| --- | --- |
| 경계값 가중치 강화 (확률적 OK)     | `dist { 0 :/ 5, ..., MAX :/ 5 }` |
| 작은 값 위주 분포 (확률적 OK)      | `dist { 1 :/ N1, ... }` |
| 시퀀스 내 시나리오 분기 (70/20/10) | `randcase` |
| 작은 도메인 정확 균등 (결정적)     | `randc` |
| 카테고리 균등 + 자연 분포          | [`solve before`](solver.md) |

---

## 외울 한 줄

> - **`dist`** = 값 가중치 (constraint 안). `:=` 값별, `:/` 범위별 — 대부분 `:/`가 정답.
> - **`randcase`** = 코드 경로 가중치 (절차적).
> - **`randc`** = 결정적 균등 (작은 도메인 빠짐없이). 균등만 가능.

---

## 흔한 오해

- ❌ `:=` 와 `:/` 가 같다 → **범위에서 정반대 효과**
- ❌ 가중치 합이 100이어야 한다 → **비율로 정규화**. 합 무관
- ❌ `dist`에 안 적힌 값도 나온다 → **안 나옴** (가중치 0)
- ❌ `dist` 가중치는 무조건 적용된다 → **다른 constraint로 잘리면 재계산**
- ❌ `dist`를 절차적 statement로 쓸 수 있다 → **constraint / `with { }` 안에만**
- ❌ `randc` 대신 `dist` 균등이면 같다 → `dist`는 **확률적**, `randc`는 **결정적**
- ❌ `randc`로 비균등 분포 가능 → **균등만**. 비균등은 `dist` 또는 별도 패턴
