# X propagation (X 전파) & 시뮬레이터 `xprop` 옵션

> **`X`(0인지 1인지 모르는 물음표 상태)**가 뒷단 회로를 타고 도미노처럼 번지는 현상과, 시뮬레이터가 `if/case`에서 `X`를 정상 숫자로 덮어버리는 착각(X-optimism)을 막기 위해 **`xprop` 옵션**을 켜는 이유.

---

## 1. `X`와 X propagation이란?

### `X` = "물음표(`?`, 0인지 1인지 알 수 없는 값)"

실제 반도체 칩에는 `X`라는 전압이 없고 무조건 `0` 아니면 `1`뿐이다. 하지만 시뮬레이터는 값을 확신할 수 없을 때 화면에 빨간색 **`X`**로 표시한다.

- **리셋(초기화)을 안 걸어준 플립플롭**의 초기값
- **아직 값을 한 번도 쓴 적 없는 메모리(SRAM)**를 읽었을 때
- **두 곳에서 같은 선에 서로 다른 값(`0`과 `1`)**을 동시에 구동했을 때

### X propagation (X 전파)

한 곳에서 생긴 `X`가 연결된 연산과 플립플롭을 타고 **도미노(전염병)처럼 뒷단 회로로 퍼져 나가는 현상**이다.

```text
[초기화 안 한 FF] ──(A = X)──> [덧셈기 C = A + B] ──(C = X)──> [다음 단 FF] ──> 출력까지 빨간 X 전염!
                                     ▲
                                  (B = 3)
```

- `A = X (모름)`, `B = 3`일 때 `C = A + B`의 결과도 알 수 없으므로 `C = X`가 되고, 이를 받는 다음 플립플롭도 연쇄적으로 `X`가 된다.
- 단, **`X & 0 = 0`**, **`X | 1 = 1`**처럼 한쪽 값만으로 결과가 확정되는 논리 게이트를 만나면 전파가 멈춘다.
- 파형 끝단에서 출력이 빨간 `X`로 나오면 **"맨 처음에 리셋(초기화)을 빼먹은 범인이 어딘가 하나 있어서 거기서부터 물음표가 전염돼 왔다"**고 역추적하면 된다.

---

## 2. 왜 기본 시뮬레이터는 위험할까? (X-optimism 문제)

다음과 같은 평범한 `if-else` 회로에서, 실수로 `sel`을 초기화하지 않아 **`sel = X`**인 상황을 보자.

```systemverilog
if (sel) y = 10;
else     y = 20;
```

상식적으로는 `sel`이 `0`인지 `1`인지 모르니 결과 `y`도 `10`일지 `20`일지 모르는 **`X`**가 나와야 맞다. 하지만 기본 RTL 시뮬레이터는 다르게 행동한다.

```text
sel = X (0인지 1인지 모름) 일 때:

  • 기본 시뮬레이터 (xprop 꺼짐) : "sel이 1은 아니네? 그럼 무조건 else로 가자!" ──> y = 20 (정상 숫자로 둔갑 ❌)
  • xprop 옵션 켬                : "sel을 모르니 결과도 알 수 없다!"            ──> y = X  (끝까지 X 전파 ✅)
```

| 구분 | `sel = X`일 때 동작 | 시뮬레이션 결과 |
| --- | --- | --- |
| **기본 시뮬레이터 (`xprop` 꺼짐)** | `if (sel)` 조건이 참(`1`)이 아니라는 이유로 **멋대로 `else` 분기로 들어가 `y = 20`**을 출력 (**X-optimism**, 낙관적 착각) | 물음표(`X`)가 멀쩡한 숫자 `20`으로 덮여 사라짐 → 초기화 버그가 숨겨진 채 **가짜 PASS** ⚠️ (실제 칩에선 `sel=1`로 켜져 오동작 가능) |
| **`xprop` 옵션 켬 (VCS / Xcelium)** | 조건식(`sel`)이 `X`이면 두 분기 결과가 다를 때 **결과 `y`도 솔직하게 `X`**로 만들어 내보냄 | 출력까지 빨간 `X`가 그대로 퍼져 **"아! `sel` 초기화를 빼먹었구나!"** 하고 숨은 버그를 즉시 발견 ✅ |

!!! warning "한 줄 요약"
    시뮬레이터가 `if/case` 문에서 `X`를 멋대로 정상 숫자로 덮어버리지(X-optimism) 못하게 막고, 끝까지 `X`로 전파시켜 **숨은 초기화 누락 버그를 잡아내려고 `xprop` 옵션을 켠다.**
