# Thread & 동기화

> 여러 프로세스를 **동시에 띄우고(fork-join)**, 서로 **기다리고·신호를 주고받는(동기화)** SystemVerilog 병렬 실행 메모.

---

## 1. 페이지

| 페이지 | 한 줄 요약 |
| --- | --- |
| [fork-join](fork-join.md) | `join` / `join_any` / `join_none`, `wait fork` / `disable fork`, 변수 캡처 함정, `process` 제어 |

    프로세스 간 동기화 도구인 **`event` / `mailbox` / `semaphore`** 페이지를 이 폴더에 추가할 예정이다.
